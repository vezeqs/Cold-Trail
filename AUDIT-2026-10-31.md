## Details

### 1. No Host/Origin validation on the local web UI (H)

**Claim (README):** "Web UI is local and locked down. Binds `127.0.0.1`; … CSP,
`Referrer-Policy: no-referrer`, `Cache-Control: no-store`".
**Evidence:** with no token configured (the documented default), the app answers
a request whose `Host` is an attacker domain and accepts a cross-origin POST:

```
GET /api/runs with foreign Host -> 200 ['runs', 'total']
POST /api/pivot cross-origin -> 202 {"job_id":"1b46f19d9d04","status":"queued"}
POST /tools/run cross-origin -> 200
```

Reproduce: build an app with `create_app(Settings(db_path=...))` and call it via
`TestClient` with `headers={"Host": "attacker.example:8765"}` and
`headers={"Origin": "https://evil.example"}`. Neither header is inspected
anywhere in `src/coldtrail/web/` (`grep -rn "Origin\|host_header"` returns
nothing).
**Cause:** binding to loopback is treated as the whole security boundary. It is
not: a browser will resolve `attacker.example` to `127.0.0.1` after the DNS TTL
(DNS rebinding), and `form-action`/`connect-src` in *our* CSP do not constrain a
page served from another origin.
**Impact:** a page the analyst visits while the UI is running can read every run,
profile, post, case, and attachment through `/api/*`, and can start pivots,
harvests, and `nuclei`/`nmap` runs with the analyst's IP.
**Fix:** reject requests whose `Host` is not a loopback name/port unless
`--allow-remote-host` is explicit; require `Origin`/`Sec-Fetch-Site` to be
same-origin for every non-GET route; keep the token requirement for anything
non-loopback.

### 2. The TLS probe bypasses the proxy/Tor and the fetcher (H)

**Claim (README):** "Tor without DNS leaks. `--tor` uses `socks5h://127.0.0.1:9050`
(remote DNS). `--proxy` supports HTTP/SOCKS proxies."
**Evidence:** with a dead proxy, every fetcher call fails but the TLS block is
still populated from a direct connection:

```
$ coldtrail --proxy http://127.0.0.1:1 --timeout 3 domain example.com --deep --json
  "rdap": null, "dns": {}, "subdomains": [], "dmarc": null,
  "security_txt": null, "favicon_mmh3": null, "takeover": null,
  "tls": { "subject_cn": "example.com", "issuer_cn": "Cloudflare TLS Issuing ECC CA 3",
           "tls_version": "TLSv1.3", ... }
```

`src/coldtrail/domain.py:452` `tls_cert_info(domain, port=443)` takes no
`Fetcher`/`Settings` and uses `asyncio.open_connection` (`domain.py:459`), so it
cannot honour the proxy, Tor, per-host pacing, the request budget, the cache, or
`robots.txt`. The only host check is `is_public_host(domain, resolve=False)` at
`domain.py:224`, which deliberately skips DNS; the raw socket then resolves and
connects to whatever the name points at.
**Impact:** `--tor`/`--proxy` users leak their real IP and the target to the
destination, and a name that resolves to loopback/link-local is connected to on
`443`.
**Fix:** resolve once, validate every address, and perform the handshake through
the configured proxy (or at minimum `asyncio.open_connection(ip, ...)` after an
explicit `is_public_host(..., resolve=True)` and refuse when `settings.tor` or
`settings.proxy` is set, with a clear message).

### 3. The test suite hits the network (H)

**Claim (README / AGENTS invariant 1):** "Tests never touch the network."
**Evidence:** running the suite with `socket.connect`/`create_connection` denied:

```
1 failed, 563 passed
FAILED tests/test_engine_upgrades.py::test_lookup_domain_deep
NetworkBlocked: test attempted real network access:
  (<socket.socket fd=14, family=2, type=1, proto=6>, ('172.66.147.243', 443))
  at src/coldtrail/domain.py:459 in tls_cert_info
```

Reproduce with a wrapper that patches `socket.socket.connect`,
`socket.socket.connect_ex`, and `socket.create_connection` before
`pytest.main(["-q", "tests"])`.
**Cause:** `@respx.mock` only intercepts httpx; `tls_cert_info` bypasses httpx
(finding 2), so the test performs a live handshake with `example.com`.
**Impact:** the suite is non-deterministic and offline-hostile, and a test run
sends traffic to a third party. It passes today only because `tls_cert_info`
swallows `OSError`.
**Fix:** inject the TLS probe (or patch it in the test) and add a session-wide
socket guard to `conftest.py` so a regression fails locally instead of silently
reaching the internet.

### 4. CSV formula injection in exports (M)

**Claim (README):** exports are "a file you can hash, redact, or hand to a
reviewer".
**Evidence:** harvested text is written verbatim:

```
>>> to_csv({"profiles":[{"username":'=HYPERLINK("http://evil.example/x","click")',
...                      "source":"github","bio":"@SUM(1+1)","url":"http://x"}]})
username,source,bio,url
"=HYPERLINK(""http://evil.example/x"",""click"")",github,@SUM(1+1),http://x
```

Same for `to_maltego_csv` (`report.py:676`), which writes `ent["value"]` and
handle-derived strings raw.
**Cause:** `csv.DictWriter` quotes for CSV syntax, not for spreadsheet formulas.
**Impact:** a target's bio or post is attacker-controlled input. Opening the
export in Excel/LibreOffice evaluates `=`, `+`, `-`, `@` cells (DDE, `HYPERLINK`,
`cmd|`), which is the classic OSINT/IR export risk.
**Fix:** prefix cells beginning with `= + - @ \t \r` with a single quote (or a
leading space) in `iter_csv`, `to_csv`, and `to_maltego_csv`; test each prefix.

### 5. Malformed `COLDTRAIL_*` env value raises a traceback (M)

**Claim (AGENTS):** error paths show "a sentence they can act on".
**Evidence:**

```
$ COLDTRAIL_TIMEOUT=abc coldtrail doctor --offline
  File ".../config.py", line 159, in _apply_env
    self.timeout = float(value)
ValueError: could not convert string to float: 'abc'
```

`Settings.load()` is called by every command and by `create_app()`, so one typo
in the environment kills the CLI, the TUI, and the server. `COLDTRAIL_CACHE_TTL=1.5`
fails the same way on `int()` (`config.py:173`).
**Fix:** parse with a helper that raises `ValueError("COLDTRAIL_TIMEOUT must be a
number, got 'abc'")` and have the Typer callback turn it into `typer.BadParameter`
(exit 2) instead of a Rich traceback.

### 6. A corrupt database raises a traceback in every command, including `doctor` (M)

**Prior audit:** finding #16 ("a corrupt DB prints a traceback") is marked fixed.
The audit hook now catches `sqlite3.Error`, but `Store.__init__` does not.

**Evidence:**

```
$ printf 'this is not a database' > bad.db
$ coldtrail --db bad.db doctor --offline ; echo $?
  File ".../store/base.py", line 28, in __init__
    self.conn.execute("PRAGMA journal_mode=WAL")
DatabaseError: file is not a database
1
```

`--db <a directory>` and `--db` in an unwritable directory give
`OperationalError: unable to open database file` the same way.
**Impact:** the one command whose job is to diagnose a broken database is the
one that crashes on it.
**Fix:** wrap the `connect`/`PRAGMA` sequence, re-raise as a dedicated
`StoreError("cannot open <path>: <reason>")`, and print it from the callback
(and from `doctor`) with exit 2.

### 7. Malformed proxy URL crashes `config` and `doctor` (M)

**Evidence:**

```
$ COLDTRAIL_PROXY='http://user:pass@example.com:notaport' coldtrail config --json
  File ".../urllib/parse.py", line 182, in port
    raise ValueError(f"Port could not be cast to integer value as {port!r}")
ValueError: Port could not be cast to integer value as 'notaport'
```

`utils.redact_url_credentials` (`utils.py:194`) reads `parts.port` and
`urlsplit` raises for a malformed bracketed netloc too
(`COLDTRAIL_PROXY='http://user:pass@[::1'` → `ValueError: Invalid IPv6 URL`).
`Settings.describe()` calls it for `proxy` and `searxng_url`, so `config --json`
and `doctor` — the commands that exist to explain a bad setting — die instead.
**Fix:** catch `ValueError` inside `redact_url_credentials` and return
`"[invalid url]"`, and validate the proxy at load time.

### 8. `Retry-After` is honoured without a cap (M)

**Evidence:** with a mocked `429` carrying `Retry-After: 7200`, one `get()`
sleeps twice for two hours:

```
raised: BlockedError HTTP 429 from example.com after 3 attempts
sleep durations requested: [7200.0, 7200.0]
```

`http.py:340-342` does `wait = float(retry_after) if retry_after.isdigit() else delay`
with no upper bound; a source (or a hostile/broken mirror) sending
`Retry-After: 86400` blocks that check for two days, and the pivot waits on
`asyncio.gather`.
**Fix:** clamp to a few seconds (`min(retry_after, MAX_RETRY_AFTER)`), and treat a
large value as `blocked` immediately rather than sleeping.

### 9. Suffix matching without a label boundary (M)

**Evidence:**

```
crtsh: ['api.example.com', 'example.com', 'notexample.com', 'www.example.com']
mx: Google Workspace Microsoft 365
```

- `domain.py:108` `value.endswith(domain)` — `notexample.com` is reported as a
  subdomain of `example.com` (CT enumeration false positive).
- `domain.py:117` `low.endswith(suffix)` — MX `mail.notgoogle.com` is reported as
  "Google Workspace", `mx.notoutlook.com` as "Microsoft 365".
- `domain.py:211` the same pattern for `TAKEOVER_CNAMES` — `notherokuapp.com`
  matches Heroku.

`domain.py:318` already does it correctly
(`host == suffix or host.endswith(f".{suffix}")`), so this is an oversight, not a
design choice.
**Fix:** use the same `host == suffix or host.endswith("." + suffix)` helper in
all three places.

### 10. Config values are not validated and unknown keys are silently ignored (M)

**Evidence** (`coldtrail --config <file> config --json`, timeout row):

| file | content | result |
| --- | --- | --- |
| cfg1 | `timeout = "abc"` | `{"key":"timeout","value":"abc","source":"config"}` — accepted |
| cfg2 | `[settings]` + `timeout = 5` | `{"key":"timeout","value":10.0,"source":"default"}` — silently ignored |
| cfg3 | `timeout = 5` + `timeoutt = 10` | typo ignored, no warning |

With cfg1 a pivot produced `0/40 checks matched (blocked: 1, error: 38, ...)`.
`Settings.load()` (`config.py:142-149`) filters to known keys and passes the rest
straight into the dataclass, which does not coerce or validate.
**Fix:** validate each key's type after load (Pydantic, or a small coercion map),
and fail on unknown keys — a typo'd config is worse than no config.

### 11. `write_private` can leave an export at `0644` (L)

**Claim (AGENTS invariant 6):** "DB/WAL/SHM/evidence/exports `0600`".
**Evidence:**

```
mode after failed chmod: 0o644
mode when chmod works:   0o600
```

`utils.write_private` does `write_bytes()` then `chmod(0o600)` inside
`contextlib.suppress(OSError)`. Between the two calls the file is `0644`, and if
`chmod` fails (unsupported filesystem, permission change, container mount) the
function still reports success.
**Fix:** open with `os.open(path, O_WRONLY|O_CREAT|O_TRUNC, 0o600)` under
`umask(0o077)` and write through that descriptor, as `Store` already does.

### 12. `infer_timezone` bins hours in the source offset, not UTC (L)

**Evidence:** the same 15 instants, written two ways:

```
same instants written with -05:00 offset -> +00:00
same instants written in UTC             -> -05:00
```

`analysis.py:178` takes `dt.hour` from `parse_dt(...)`, which preserves the
timestamp's own offset. AGENTS invariant 2 says timestamps must be handled
through `epoch_seconds()`/UTC; this path bypasses it, so platforms that emit
local offsets shift the inferred timezone by that offset.
**Fix:** `dt.astimezone(UTC).hour`, and add a test with the two encodings of the
same instants.

### 13. Corrupt `args_json` crashes `coldtrail audit` (L)

**Evidence:** insert `args_json = '{not json'`, then:

```
$ coldtrail audit
  File ".../store/cases.py", line 26, in audit
    item["args"] = json.loads(item.pop("args_json"))
json.JSONDecodeError: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)
```

AGENTS invariant: "Corrupt JSON rows: use `utils.json_loads(value, default)`".
`store/cases.py:26` is the one remaining raw `json.loads` on a stored column.
**Fix:** `json_loads(item.pop("args_json"), {})`.

### 14. Two silent-empty CLI paths (L)

```
$ coldtrail timeline --since yesterday        # unparseable bound
Timeline (0)                                  # empty table, exit 0

$ coldtrail export 1 --format csv --table nope -o out.csv
wrote out.csv                                 # 0 bytes, exit 0
```

`store.timeline` falls back to `created_at >= 'yesterday'` (string compare) when
`epoch_seconds()` returns `None` (`store/queries.py:326-332`), and `iter_csv`
returns nothing for an unknown table (`report.py:105`). Both are silent wrong
answers; the user cannot tell "no data" from "bad input".
**Fix:** reject an unparseable `--since`/`--until` with exit 2, and validate
`--table` against `CSV_TABLES` before writing.

### 15. Command-count claim is wrong (L) — not a bug

`AGENTS.md`: "The CLI exposes 48 top-level commands and 61 leaf commands."

```
top-level: 48
leaf: 13            (case 5, source 4, evidence 4)
```

61 is the total command count (48 + 13). On investigation the wording is
deliberate: `tests/test_docs_drift.py` asserts that "61 leaf commands" equals
top-level plus subcommands, i.e. "leaf" means "a command that actually runs"
(a top-level command without a subcommand is a leaf). The sentence is
imprecise, not false, and changing it would break its own drift test. Marked
**not a bug** and left alone.

### 16. Validating a host then resolving it again is a TOCTOU (M)

**Claim (README):** redirects and targets are validated before a fetch.
**Evidence:** `ensure_public_target` resolves the name, but httpx resolves it
again at connect time, so a hostile DNS can answer the check with a public
address and the connection with `10.x.x.x`.
**Fix:** `http._PinnedTransport` resolves once through
`security.resolve_public_ips`, rewrites the request to the validated address,
and keeps the original `Host` header and TLS SNI name (`sni_hostname`), so
certificate verification still matches the hostname. Proxied clients skip
pinning (the proxy resolves); `_owns_routing()` passes the request through
untouched when a test transport owns the pool, so respx fixtures still match on
hostnames.
**Status:** fixed, `test_pinned_transport_rewrites_the_url_but_keeps_host_and_sni`,
`test_pinned_transport_refuses_a_private_answer`.

### 17. robots.txt redirect was an unvalidated internal GET (L)

**Evidence:** `_fetch_robots` used the client with `follow_redirects=True` and
never looked at the final URL, so a host could redirect the probe into loopback.
**Fix:** the final host must be public (`is_public_host(..., resolve=True)`),
otherwise the rules are ignored.
**Status:** fixed, `test_robots_redirect_to_private_host_is_ignored`.

### 18. The login cookie is a bearer credential (L)

**Claim:** the docstring said a cookie leak "does not expose the API token".
**Evidence:** the cookie was a deterministic HMAC of the token with no expiry
server-side; anyone holding it could use the UI until the token changed.
**Fix:** the cookie is now `"<issued>.<hmac(token, issued)>"`,
`_cookie_is_valid` rejects a tampered or expired value, and the docstring says
plainly that it is a bearer credential for its lifetime.
**Status:** fixed, `test_expired_cookie_is_rejected`,
`test_tampered_cookie_is_rejected`.

### 19. Non-public ranges depended on the interpreter (L)

**Evidence:** whether `100.64.0.0/10` (CGNAT) counted as private changed between
Python 3.12 and 3.13 because it tracks `ipaddress.is_private`.
**Fix:** `security.NON_PUBLIC_NETWORKS` pins the ranges explicitly (CGNAT,
benchmarking, documentation, reserved, IPv6 unique-local/link-local).
**Status:** fixed, `test_non_public_ranges_are_blocked`.

### 20. Evidence scale (L)

**Evidence:** `add_evidence(source_path=...)` called `read_bytes()`, so a 50 MB
upload was held in RAM; `verify_evidence` fetched up to 10,000,000 attachments
in one query.
**Fix:** `_store_blob_from_path` streams the file into a temp file under the
evidence root while hashing, then renames it into the shard (same filesystem,
so no `EXDEV`); `verify_evidence` pages through `attachments(limit, offset)`.
**Status:** fixed, `test_add_evidence_streams_from_a_path`,
`test_verify_evidence_pages_through_attachments`.

## Remaining risks

- The initial host check is still a TOCTOU for proxied clients: `--proxy`/`--tor`
  leaves name resolution to the proxy. Direct HTTP connections are pinned to the
  validated address (`_PinnedTransport`), and the TLS probe resolves and pins too.
  Keep the web UI on loopback or behind an authenticating proxy.
- `example.com` was contacted once during the original audit by the test in
  finding 3. That test now patches the TLS probe and `tests/conftest.py` blocks
  real sockets, so the suite is offline.
- Correlation, timezone inference, and at-rest encryption remain documented
  limits in `SECURITY.md` and `README.md`; none is a regression from this pass.
