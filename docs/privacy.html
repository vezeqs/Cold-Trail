Privacy first

Your investigation stays yours.

ColdTrail is built for local, accountable OSINT. There is no telemetry, no cloud backend, and no hidden collection. The only network requests are the sources and tools you explicitly run.

What we guarantee

No telemetry

No analytics, crash reporting, update checks, or phone-home. doctor --offline skips even the optional reachability probe.

Local, owner-only storage

SQLite, WAL/SHM, and evidence blobs are created 0600; evidence directories are 0700. There is no cloud component.

Raw bodies opt-in

Normal runs do not retain raw HTTP responses. Use --raw only for replay or contract fixtures; disable the cache with --no-cache.

No third-party images by default

Avatar hashing (--avatar-hash) downloads profile images from source platforms, so it is off unless you ask for it.

No identifier indexes

Email targets are SHA-256 hashed in cache/raw keys. API keys are never written there. HIBP, EmailRep, and Hunter use auth headers.

Tor without DNS leaks

--tor uses socks5h://127.0.0.1:9050 so DNS resolves through the proxy. --proxy supports HTTP/SOCKS.

Locked-down web UI

Binds 127.0.0.1; non-loopback binds require --token; HMAC-derived cookies; CSP, no-referrer, no-store; no third-party assets.

Redact and encrypt

Exports support --redact; encrypted exports use PBKDF2 + Fernet. Evidence is content-addressed and verifiable.

Retention controls

--retention-days N or prune --days N removes old runs, raw/cache rows, audit entries, and orphan evidence blobs.

Breach privacy

Breach features are metadata-only. Pwned Passwords uses k-anonymity and never sends or logs the password or full hash.

Limits you should know

Privacy claims are only useful if they are honest.

  • Sources receive the target. Every source you probe gets the username or email you asked about — that is inherent to OSINT. Choose sources deliberately.
  • The database is not encrypted at rest by default. Use full-disk encryption on shared or portable machines.
  • --raw and the HTTP cache can retain third-party content. Prune them or run with --no-cache --no-raw when that matters.
  • External tools are third-party software. Their own privacy behavior is outside ColdTrail's control.
  • This is not legal advice. You are responsible for lawful basis, scope authorization, and platform terms.

Verify it yourself

Privacy claims should be testable. These commands show the posture and remove old data.

uv run coldtrail doctor --offline --json
uv run coldtrail prune --days 30 --vacuum
uv run coldtrail export 3 --format json --redact
COLDTRAIL_RETENTION_DAYS=30 uv run coldtrail serve --token "$(openssl rand -hex 24)"

Read the implementation: SECURITY.md, http.py, and store/base.py.
