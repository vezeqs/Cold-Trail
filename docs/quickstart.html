5-minute setup

Quickstart

From clone to a correlated identity graph in four commands.

1. Install

Requires Python 3.11+ and uv. No API keys are needed to start.

git clone https://github.com/slopmanufacturer/coldtrail
cd coldtrail
uv sync
uv run coldtrail doctor

2. Run a pivot

Curated sources first. Add --web for the 432-site declarative corpus, or --expand to follow structured links.

# Username across curated API sources
uv run coldtrail pivot alice

# Email, then follow linked handles from Gravatar/Keybase/EmailRep
uv run coldtrail pivot alice@example.com --expand

# Multi-hop: email -> username -> email
uv run coldtrail pivot alice@example.com --expand --depth 2

# Generated handle variants (_official, leet, dotted, ...)
uv run coldtrail pivot alice --variants

# Everything, including the web corpus
uv run coldtrail pivot alice --web --json

Results are saved as a run. Query it with runs, profiles, links, clusters, and entities.

3. Open an interface

Web UI

uv run coldtrail serve --open
Binds 127.0.0.1:8765. Add --token before exposing it.

Terminal UI

uv run coldtrail tui
p pivot the focused row, h harvest, d diff the two latest runs.

JSON API

GET /api/runs, GET /api/runs/{id}/graph, POST /api/pivot. Docs at /api/docs.

4. Optional API keys

Set environment variables or put them in ~/.config/coldtrail/config.toml.

VariableUnlocks
GITHUB_TOKENHigher GitHub API limits, commit and key metadata
HIBP_API_KEYHave I Been Pwned breach lookup
EMAILREP_API_KEYEmailRep reputation details
HUNTER_API_KEYHunter.io email verification
X_BEARER_TOKENX/Twitter API v2 profile lookup
SHODAN_API_KEYShodan host enrichment in ip / web tools

Common workflows

# Batch pivots
uv run coldtrail batch alice bob carol -s social
uv run coldtrail batch -f targets.txt --json

# Harvest posts, then only new ones next time
uv run coldtrail harvest alice -s reddit -n 200 --incremental

# Follow graph (Bluesky, Mastodon, GitHub)
uv run coldtrail graph alice -s bluesky

# Compare two runs
uv run coldtrail diff 3 4

# Re-correlate stored profiles
uv run coldtrail recluster --run 3

# Cases and evidence
uv run coldtrail case new operation-blue
uv run coldtrail case add operation-blue --run 3
uv run coldtrail evidence add photo.jpg --run 3
uv run coldtrail case export operation-blue --format stix -o case.json

# Infrastructure and identity
uv run coldtrail domain example.com --deep
uv run coldtrail ip 1.1.1.1 --deep
uv run coldtrail ct example.com
uv run coldtrail phone +351912345678
uv run coldtrail breach alice@example.com --all

# Export
uv run coldtrail export 3 --format html -o dossier.html
uv run coldtrail export 3 --format stix -o bundle.json

External tools

uv run coldtrail integrations          # what is installed, with hints
uv run coldtrail run maigret alice --json
uv run coldtrail run instaloader alice --json
uv run coldtrail ingest spiderfoot.json --format auto

Troubleshooting

SymptomFix
Global option ignoredPut --db, --config, --tor before the subcommand.
Many blocked resultsExpected for bot-walled sites. Try --proxy / --tor, or use the matching external tool.
Rate limitedLower --concurrency, raise pacing via config, or set the provider API key.
False positiveUse --json and inspect detail; record a contract fixture with source verify --record.
Web UI exposedAlways set --token and COLDTRAIL_TRUST_PROXY=1 behind a proxy.
