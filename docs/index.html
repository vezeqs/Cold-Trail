Find the person behind the handle.

A local-first OSINT toolkit that pivots usernames and emails across 482 public sources, harvests profiles and posts into one SQLite store, correlates identities with calibrated confidence, and exports evidence-grade dossiers — from a CLI, a TUI, or a local web UI.

Get started View source 
git clone https://github.com/vezeqs/Cold-Trail
cd Cold-Trail && uv sync
uv run coldtrail pivot alice
uv run coldtrail serve --open

Why ColdTrail

Built for investigations that need reproducible, auditable results — not a pile of browser tabs.

Coverage

482 sources

50 curated sources plus 432 declarative site definitions generated from the Sherlock corpus. Handle variants and multi-hop expansion included.

Evidence

Content-addressed storage

Every run, profile, post, link, and entity lands in SQLite. Raw responses and attachments are hashed (SHA-256) and verifiable later.

Correlation

Explainable identity clusters

Additive scoring with per-signal reasons, Jaro-Winkler handle similarity, avatar perceptual hashes, EXIF, and cryptographic identifiers.

Interfaces

CLI, TUI, and web

Scriptable commands, a Textual terminal console, and a FastAPI app with SSE-streamed pivots and an interactive graph — all over the same database.

Integrations

Bring your own tools

Import findings from Maigret, Sherlock, Holehe, theHarvester, Subfinder, Instaloader, twscrape, SpiderFoot, Maltego, and more.

Output

Eleven export formats

JSON, JSONL, CSV, GraphML, GEXF, DOT, HTML, Markdown, STIX 2.1, SARIF 2.1.0, and Maltego CSV — with optional redaction and encryption.

Operations

Inspectable configuration

coldtrail config shows every effective setting and its source, with secrets redacted. coldtrail schema publishes JSON Schema contracts for the --json payloads.

How it works

One pipeline, shared by every interface.

1. Pivot

Probe curated APIs and declarative sites with per-host pacing, caching, retries, circuit breaking, and optional Tor/proxy.

2. Harvest

Pull profile fields, paginated posts, follow graphs, and profile-change history with incremental cursors.

3. Correlate

Score pairs, build clusters, extract emails/wallets/keys/coordinates, and store the reasons for every link.

4. Report

Export a run or a multi-run case dossier in the format your workflow already uses.

Privacy and safety by default

Public data only. Use ColdTrail for authorized research, journalism, threat intelligence, and defensive security. You are responsible for applicable law, platform terms, and scope authorization.

No telemetry. Local-only storage with owner-only permissions. Raw HTTP bodies are off by default. Email targets are hashed in cache keys. Tor uses remote DNS. The web UI binds to 127.0.0.1 and uses HMAC-derived cookies, CSP, and no-referrer. Breach features report metadata only; Pwned Passwords uses k-anonymity. Read the full privacy design.
