Help

Three interfaces over one local database: CLI, TUI, and this web UI.

Start here

  1. Run a pivot for a username or email (curated sources or the full web corpus).
  2. Open the resulting run to see profiles, correlations, entities, posts, and evidence.
  3. Harvest posts, collect a follow graph, or run an external tool.
  4. Attach runs to a case and export a merged dossier.

Global options

Options such as --db, --config, --concurrency, --timeout, --proxy, --tor, and --max-requests must come before the command:

larpharvester --db case.db pivot alice

Default database: {{ settings.db_path }}

External tools & evidence

larpharvester integrations lists detected binaries and install hints. Run one with larpharvester run <tool> <target>; raw output is stored as evidence.

Imports accept Maltego CSV, SpiderFoot JSON, theHarvester JSON, and generic JSON. Evidence is content-addressed (SHA-256) and can be downloaded from each run page or via larpharvester evidence export ID -o file.

Web API

Interactive docs: /api/docs. Key endpoints: POST /api/pivot, GET /api/runs, GET /api/runs/{id}/graph, GET /api/diff, GET /api/jobs/{id}/stream, GET /healthz.
